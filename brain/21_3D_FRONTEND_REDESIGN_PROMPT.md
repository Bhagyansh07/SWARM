# SWARM 3D Frontend Reference Brief

Study patterns from github.com/brunosimon/folio-2019 (visual ambition) and github.com/pmndrs/react-three-examples (idiomatic React Three Fiber code correctness) before writing the 3D scene. Use @react-three/fiber and @react-three/drei as the base libraries — don't hand-roll raw Three.js in plain React state.
